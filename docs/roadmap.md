# Roadmap to 1.0

Luca's plan, from 0.6.x (site live, logos done) to 1.0. Phases run in order; this repo only builds the site. Tools are built elsewhere.

## Phase 1: Scope and shape (now)
Decide exactly what the site covers and how it is structured, so it is a semi-professional but fun portfolio that holds:
- documentation for all of Luca's personal projects;
- his research, with room to grow into his capstone project;
- the resume.

Output: an agreed site map, a content model (what each kind of page contains and where its source lives), and the structural changes to get there. Luca writes all the prose; this phase builds structure only.

Includes any **prep for the editing tool** (see below) that the tool session asks for or that the content model makes obvious.

## In parallel: Ice Cavern session (elsewhere)
Builds the hub website and, likely, an **editing tool** for all of Luca's projects (Minuet, Nocturne, Ice Cavern, Prelude). **No tool development happens in this repo or session.** Its outputs arrive here as handoffs; this repo adapts to them (content formats, schemas, conventions).

## Phase 2: Visual pass
Theming, animation and possibly sound. Philosophically minimal, to keep a semi-professional feel:
- every effect earns its place;
- respects `prefers-reduced-motion`;
- any sound is off by default and opt-in;
- nothing gets in the way of reading.

## 1.0
All phases done, content written by Luca, `npm run todos` empty or deliberately parked, checks green.
