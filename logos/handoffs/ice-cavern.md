## The look: ice palette, light first

These are the colours for the `ice-cavern` token set (hub handoff §6). Light mode is the default.

| Role | Colour |
|---|---|
| Page background | `#f2f8fc` (the logo tile's top colour) |
| Raised surface / tint | `#d9e9f4` |
| Highlight | `#ffffff` |
| Light accents | `#d2ecf8`, `#8cc4e3` |
| Mid (links, buttons) | `#4f9cc9`, `#2878ad` |
| Deep (headings, main colour) | `#185a8a`, `#0f3d63` |
| Deepest (body text) | `#08223a` |

- **Contrast:** check every text pair for WCAG contrast of 4.5:1 or better. On the light background, use the deep end for text, and the mid colours only where they pass (e.g. `#2878ad` for large text or icons).
- **Optional dark mode:**
  - background `#08172a` / `#12263a` (the dark logo tile);
  - text `#d2ecf8` / `#ffffff`;
  - accents `#8cc4e3` / `#4f9cc9`;
  - swap `logo.svg` for `logo-dark.svg`. The medallions work on both backgrounds.
- **Motion ideas within the palette:** frost or shimmer on door hover, crystal facets catching light. Respect `prefers-reduced-motion` (hub handoff §6).
- **Type:** Minuet uses Hylia Serif (self-hosted) for headings. It is one candidate for the type pairings in the design directions. If Luca picks it, ask him for the font file: it is in the Minuet repo at `src/assets/fonts/`.

**Starting colours for the other theme token sets** (hub handoff §6: forest, shadow):
- **forest**, from Minuet of Forest: background `#f4f6f0`, tint `#dfe9d6`, main `#1f4d34`, link `#2d6a46`, text `#1d2a21`, muted `#4f6356`.
- **shadow**, a proposal taken from the Nocturne logo, dark only: background `#0c0814` / `#1e1330`, then `#24103d`, `#3a1763`, `#55208f`, `#7330bd`, `#9550dc`, `#c79af0`, highlight `#f3e6ff`.

## Project logos on the doors

- **Registry field.** Add an optional `logo` field to each entry in `src/data/projects.json` (hub handoff §2): a path to the project's logo file.
- **Display.** The door card shows the logo at about 40px beside the name. The images are decorative (`alt=""`); the project name labels the door.
- **No logo yet.** Entries without one (Temple of Time and Saria's Song, for now) fall back to the existing door design, e.g. a badge in the project's theme colour. Don't invent logos for them; Luca may have them made later.
- **Backgrounds.** The logos have their own tiles (light, cream, dark), so they read on any background.
- **Addresses.** Keep them where the registry already has them. This handoff deliberately contains none.

## Footer with the medallion and version

This is the footer component from the hub handoff §6. It's the same quiet footer Minuet of Forest uses; adapt it to the hub's components and tokens rather than copying Minuet's code.

**Layout**
- One footer at the very end of every page. Make the page a full-height column (body `min-height: 100vh; display: flex; flex-direction: column`, main `flex: 1`), so on short pages it sits at the bottom. It is not sticky or fixed.
- Style it quietly: a thin top border in a soft theme colour, small muted text (about 0.85rem), little padding.
- Left: credits or links. Bottom right: `medallion-compact.svg` at about 36px, then the version as `v1.2.3`.
- Use flex with `flex-wrap: wrap; justify-content: space-between; align-items: center`, so nothing overflows at 360px width.

**The version link**
- The medallion and the version text are one link, to the changelog (the repo's `CHANGELOG.md` view, or a changelog page).
- The image is decorative (`alt=""`); the visible "v1.2.3" names the link.
- Keep visible focus, and hide the footer in print styles.

**Versioning**
- `package.json`'s `version` is the one source of truth; the footer reads it, never a hard-coded number.
- **Ask Luca which version number to start at** before setting it.
- Add `CHANGELOG.md`, newest entries first: `## 1.2.3 (YYYY-MM-DD)` with short bullets.
- Bump the version with every release, and note the rule in the repo's `CLAUDE.md`.

## Steps
1. Commit this file at `docs/handoffs/ice-cavern-logo-handoff.md`, and reference it from `CLAUDE.md` next to the hub handoff.
2. Put `files/` in the hub's static assets (e.g. `public/logo/` and `public/logo/projects/`), keeping the filenames.
3. In the shared head, add the following, with base-path-aware URLs (hub handoff §5: the hub may be mounted under a subpath):
   - `<link rel="icon" href=".../logo.svg" type="image/svg+xml">`
   - `<link rel="icon" href=".../favicon.ico" sizes="32x32 48x48">`
   - `<link rel="apple-touch-icon" href=".../apple-touch-icon.png">`
   - `<link rel="manifest" href=".../site.webmanifest">`
4. Fill the `ice-cavern` token set from the palette above, and seed `forest` and `shadow` from their starting colours.
5. Header: the logo at about 40px left of the site name, inside the home link, decorative.
6. Add the `logo` registry field and the door logos.
7. Build the footer and versioning.
8. Run the design-direction step (hub handoff §6) within this palette and logo, and let Luca pick.
9. Check visually in the dev server: light mode (and dark if built), keyboard focus, 360px width, print. Commit in small steps.
