# Handoff: Nocturne of Shadow logo, icons and footer

For the Claude Code session working on Nocturne of Shadow. It installs the shadow medallion logo (see `preview.png`), the icon set, a link back to Minuet of Forest and a versioned footer.

The files are generated by the shared logo engine in Luca's Minuet of Forest repo (`scripts/logos/shadow.mjs`, run `node scripts/make-logos.mjs shadow`). Do not hand-edit them; ask Luca to have them regenerated there if something needs changing.

## Files
| File | Use |
|---|---|
| `files/logo.svg` | The mark: the shadow medallion's emblem on a dark tile. Browser tab icon (SVG favicon), site header next to the site name, login page |
| `files/favicon.ico` | Fallback tab icon, 32 + 48px |
| `files/apple-touch-icon.png`, `files/icon-192.png`, `files/icon-512.png`, `files/site.webmanifest` | Bookmarks and home-screen icons. The manifest's icon paths are relative, so keep these files in one folder |
| `files/medallion-compact.svg` | Footer medallion (see below) |
| `files/medallion.svg` | Full medallion with runes, for large display (96px and up), e.g. on the login page if wanted |
| `files/minuet-mark.svg` | Minuet of Forest's mark, for the link back to Luca's public site |

## Steps
1. Put the files in the folder the site serves static assets from, keeping the filenames.
2. In the shared page head, add:
   - `<link rel="icon" href=".../logo.svg" type="image/svg+xml">`
   - `<link rel="icon" href=".../favicon.ico" sizes="32x32 48x48">`
   - `<link rel="apple-touch-icon" href=".../apple-touch-icon.png">`
   - `<link rel="manifest" href=".../site.webmanifest">`

   Adjust the paths to the site's base path.
3. Header: `logo.svg` at about 40px, left of the site name, both inside the home link. The image is decorative (`alt=""`) because the name labels the link.
4. Login page: show `logo.svg` (or `medallion.svg`, if it's large there) above the form.
5. Link back to Minuet of Forest: a small link with `minuet-mark.svg` (about 22px) and an accessible name such as "Minuet of Forest". The URL is `https://wander22lstr.github.io/minuet-of-forest/`; ask Luca whether he has set up a custom domain since. This is the one link from Nocturne to the public site. Minuet's side has the matching hidden link to Nocturne's login page.
6. Build the footer and versioning below. The footer can hold the Minuet link on the left and the medallion and version on the right.
7. Check: tab icon, header, login page, keyboard focus, no horizontal scroll at 360px, print. Run the project's tests and linters. Commit in small steps.

## Don't

- Don't put anything about Nocturne's contents on Minuet of Forest, or link to any private project other than Minuet.

## Footer with the medallion and version

The same quiet footer Minuet of Forest uses. Adapt it to this project's templates and CSS. Don't copy Minuet's code literally.

**Layout**
- One footer at the very end of every page, after the main content. Make the page a full-height column (body `min-height: 100vh; display: flex; flex-direction: column`, main `flex: 1`), so on short pages the footer sits at the bottom rather than mid-screen. It is not sticky or fixed.
- Separate it with a thin top border in a soft theme colour, small muted text (about 0.85rem) and little padding. It shouldn't draw attention.
- Left: the existing footer content (credits, links), if any.
- Bottom right: the **compact medallion** at about 36px, then the version as `v1.2.3`. Use `display: flex; flex-wrap: wrap; justify-content: space-between; align-items: center` so it wraps instead of overflowing on a 360px-wide phone.

**The version link**
- The medallion and the version text are one link, to the project's changelog (the `CHANGELOG.md` view in the repo's web UI, or a changelog page if the project has one).
- The image is decorative (`alt=""`); the visible "v1.2.3" text names the link.
- Keep visible keyboard focus.
- Hide the footer in print styles.

**Themes**
- If the project has light and dark themes, swap the medallion with the theme, the same way the header logo already swaps.

**Versioning**
- Keep one source of truth for the version: the project's existing version field (`pyproject.toml`, `package.json`), or a `VERSION` file if it has none. The footer reads it; never hard-code the number in a template.
- **Ask Luca which version number to start at** before setting it.
- Add a `CHANGELOG.md` with newest entries first: `## 1.2.3 (YYYY-MM-DD)` followed by short bullets. Put a first entry for the current version and one for this logo/footer change.
- Bump the version and add a changelog entry with every release from now on. Note this in the project's `CLAUDE.md` (or equivalent) so future sessions keep it up.
