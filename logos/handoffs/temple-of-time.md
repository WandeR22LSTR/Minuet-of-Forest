# Handoff: Temple of Time logo and icons

**Written:** 2026-10-20
**For:** the Claude Code session working on Temple of Time. It installs the Triforce logo (see `preview.png`), the icon set, the Discord bot avatar and the large medallion for the documentation.

The files are generated by the shared logo engine in Luca's Minuet of Forest repo (`scripts/logos/temple.mjs`, run `node scripts/make-logos.mjs temple`). Do not hand-edit them; ask Luca to have them regenerated there if something needs changing.

## The logo

The Triforce above the Door of Time, in the temple's grey-blue stone, lit from the top left like Luca's other project logos.
- **Mark:** the Triforce raised from a stone tile, light or dark. Used for icons, headers and Ice Cavern's door for this project.
- **Medallion:** the shared twelve-sided plate with runes, the Triforce engraved into its face. For large display only (the documentation); there is no small version.

## Files
| File | Use |
|---|---|
| `files/logo.svg` | The mark on a pale stone tile: browser tab icon (SVG favicon), dashboard header |
| `files/logo-dark.svg` | The mark on a dark stone tile, for a dark interface |
| `files/favicon.ico` | Fallback tab icon, 32 + 48px |
| `files/apple-touch-icon.png`, `files/icon-192.png`, `files/icon-512.png`, `files/site.webmanifest` | Bookmarks and home-screen icons. The manifest's icon paths are relative, so keep these files in one folder |
| `files/medallion.svg` | Full medallion, for the documentation (README or docs pages), 96px and up |
| `files/medallion-1024.png` | The medallion as a large transparent PNG, where SVG doesn't display |
| `files/discord-avatar-1024.png` | The Discord bot's avatar: square dark tile, sized to clear Discord's circular crop |

## Steps
1. Put the files in the project, keeping the filenames: the web files where the dashboard serves static assets, the medallion where the documentation keeps its images (e.g. `docs/images/`).
2. Dashboard: in the shared page head, add (adjusted to its base path):
   - `<link rel="icon" href=".../logo.svg" type="image/svg+xml">`
   - `<link rel="icon" href=".../favicon.ico" sizes="32x32 48x48">`
   - `<link rel="apple-touch-icon" href=".../apple-touch-icon.png">`
   - `<link rel="manifest" href=".../site.webmanifest">`
3. Dashboard header: `logo.svg` (or `logo-dark.svg` on a dark theme) at about 40px, left of the name, inside the home link, decorative (`alt=""`).
4. Documentation: `medallion.svg` (or the PNG) as a large image at the top of the README or docs index, about 200–300px wide, with `alt="Temple of Time"`.
5. Discord bot avatar: Luca uploads `discord-avatar-1024.png` in the Discord Developer Portal himself. List the step for him; don't touch his accounts.
6. Check the tab icon, header and docs image. Run the project's tests and linters. Commit in small steps.

## Colours
