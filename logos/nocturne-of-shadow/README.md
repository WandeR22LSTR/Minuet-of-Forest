# Nocturne of Shadow logo

The shadow medallion: an inverted three-faced pyramid with its peak at the centre, and three orbs. Source: `scripts/logos/shadow.mjs`. Positions were measured from the in-game medallion. Lit from the top left like the other project logos, so the pyramid's top face is bright, its left face mid-tone and its right face dark.

| File | Use |
|---|---|
| `logo.svg` | The mark on a dark tile: tab icon, header, login page |
| `medallion.svg` | Full medallion with the rune band, for large display (96 px and up) |
| `medallion-compact.svg` | Medallion without runes, for small sizes |
| `favicon.ico` | 32 + 48 px |
| `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` | Bookmarks and home screen |

Colours (dark purple and black, a proposal for Nocturne's palette):

| Deepest shadow | `#0e0716` |
| Shadow | `#24103d`, `#3a1763` |
| Mid | `#55208f`, `#7330bd` |
| Light | `#9550dc`, `#c79af0` |
